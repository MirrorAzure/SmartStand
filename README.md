# Голосовая навигация по сайту

## Запуск в Docker
```bash
docker compose up -d
```

## Пример взаимодействия React с сервисом
Чтобы воспользоваться голосовой навигацией, требуется использовать компонент `AudioRecorder.js`, который находится в `frontend-test/src`.

Его надо поместить как можно ближе к верхушки иерархии компонентов. 

К примеру, в компоненте `App.js`.
У компонента `AudioRecorder.js` можно редактировать стили и также обработку информации.

**Взаимодействие с сервисом не рекомендуется менять!**


## Данные для сервиса
Также системе для работы необходим список ссылок на ресурсы. Он задаётся в файле `data/links.json` и должен иметь следующую структуру:
```json
[
    {
        "ru": "Название ссылки",
        "en": "Link Name",
        "link": "Адрес ссылки"
    },
    ...
]
```

## Выходные данные
При обнаружении ключевого слово сервер передаёт через WebSocket JSON-объект со следующей структурой:
```json
{
    "status": 1,
    "payload": {
      "link": "https://istokmw.ru/news/",
      "name": "Новости Истока"
    },
    "transcript": "Открой новости Истока",
    "score": 0.25 // Уверенность модели
}
```
